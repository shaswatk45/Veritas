Observational causal inference · doubly-robust · ground-truth validated

Correlation gives the wrong answer.
Sometimes the wrong sign.

In observational data, treated and untreated groups differ systematically — sicker patients get the aggressive therapy, so a naive comparison makes it look harmful when it isn't (or vice-versa). Veritas recovers the true causal effect anyway: doubly-robust estimation, heterogeneous effects, and an honest accounting of how strong a hidden confounder would have to be to overturn the finding — all proven against benchmarks where the truth is known.
